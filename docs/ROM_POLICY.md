# ROM and Asset Policy

This project is a clean-room emulator implementation. The repository must not contain commercial game ROMs, BIOS files, copyrighted box art, or proprietary game assets unless their license explicitly permits redistribution.

## Development ROMs

Use homebrew, public-domain, self-authored, or otherwise legally redistributable ROMs. For private compatibility testing, keep ROM files outside the Git repository and configure a local test path.

## Catalog metadata

Game titles, categories and technical metadata may be represented independently from ROM binaries. Metadata should not imply that a ROM is included.
